Двухуровневая витрина · Спецификация

Товары представлены на двух уровнях из общих SKU-атомов: нижний — магазин селлера, верхний — каталог Системы. Архитектура витрины — ключевой компонент Marketplace Service.
Синхронизировано с Правилами системы · редакция 2 · пул документов Системы
Агентный слой и полный цикл. Витрина работает совместно с агентом покупателя (виджет 🤖 на витрине) и инструментами селлера (join-form → wizard → sku-crud → ЛК). Полный цикл: селлер создаёт магазин через wizard → данные записываются в БД → API отдаёт их витрине и агенту → покупатель покупает через карточки (MIGRATED) или через агента (NETWORK) → заказ → клиринг. Два каталога: 🟢 каталог Системы (участники) + ⚪ каталог рынка (парсинг).

Зачем два уровня ст. 9.1

Одна витрина не может обслужить два разных субъекта: бренд селлера и бренд Системы. Магазин сохраняет бренд селлера (стимул группы 1 — «Неорганизованные»); каталог даёт агрегацию и сетевой эффект (общее достояние всех участников). SKU-атом соединяет оба уровня без дублирования товара.

SKU-атом ст. 9.4

Один товар существует как единая карточка-SKU и виден одновременно в магазине селлера (под его брендом) и в каталоге Системы (в общем поиске) без дублирования.

SKU — структура карточки { sku_id: "SKU-2027-001", // глобально уникальный seller_id: "PTR-12345", // владелец-селлер (FK → Registry) source_type: "MIGRATED" | "NETWORK", // откуда пришёл покупатель (ст. 10) // === Контент (управляется селлером) === title: "Хлеб бородинский на закваске", description: "Ржано-пшеничный, 48ч ферментация...", images: ["url1.jpg", "url2.jpg", ...], // до 10 фото category_id: "CAT-BREAD-001", // из справочника категорий tags: ["без дрожжей", "крафт", "закваска"], // === Цена и наличие === price: 450, // в рублях currency: "RUB", stock: 24, // остаток stock_reserved: 3, // в заказах (PENDING) unit: "шт", // единица измерения // === Логистика === weight_g: 780, dimensions_mm: { l: 250, w: 120, h: 80 }, fulfillment_id: "PTR-67891", // привязанный фулфилмент warehouse_id: "WH-001", // склад хранения shipping_zones: ["MSK", "MSK-OBL"], // зоны доставки // === Отображение в витринах === visible_shop: true, // видим в магазине селлера visible_catalog: true, // видим в каталоге Системы seller_brand: { // брендирование для магазина name: "Масса Матере", logo_url: "logo.png", accent: "#8B4513" }, // === Мета === status: "ACTIVE" | "DRAFT" | "OUT_OF_STOCK" | "ARCHIVED", created_at: "2027-06-15T10:30:00Z", updated_at: "2027-08-12T14:22:00Z", rating: 4.7, reviews_count: 23, orders_count: 156 }

Правила атомарности SKU

ПравилоОписание
Один SKU — один товарНикакого дублирования. Карточка создаётся один раз и проецируется на оба уровня витрины
Владелец = селлерТолько селлер может создавать, редактировать, снимать с публикации свои SKU
visible_shop / visible_catalogДва независимых флага. Селлер может скрыть товар из каталога (оставить только в магазине) — но не наоборот
Цена единаяОдна цена для обоих витрин. Нет «цены для каталога» — защита доверия покупателя
Контент единыйФото, описание, характеристики — одни и те же. Но в магазине — под брендом селлера, в каталоге — под зонтичным
Stock единыйОдин остаток, одно резервирование. Откуда бы ни пришёл заказ — списание из одного стока

Маршрутизация покупателей ст. 11

Организатор маршрутизирует покупателей из каталога (сетевой приток) между селлерами. Маршрутизация касается только каталога — в магазине селлера маршрутизации нет.

Алгоритм маршрутизации

1
Запрос покупателя: поиск «хлеб на закваске» в каталоге. source_type = NETWORK
↓
2
Elasticsearch: full-text search → набор SKU из разных магазинов (Масса Матере, Пекарня Х, ...)
↓
3
Фильтрация: наличие на складе (stock > 0), зона доставки (shipping_zones ∩ buyer_zone), статус селлера (ACTIVE)
↓
4
Ранжирование (scoring):
score = w1×relevance + w2×rating + w3×price_rank + w4×priority_boost + w5×geo_proximity
где priority_boost > 0 для гр. 2 в первые 2–3 мес (ст. 11.2)
↓
5
Выдача: отсортированный список SKU. Покупатель видит товары от разных селлеров в порядке score

Приоритетная маршрутизация (ст. 11.2)

priority_boost для группы 2 («Разочаровавшиеся»): Условия активации: - seller.group == "DISAPPOINTED" - seller.joined_at + 90 дней > now() // первые 2–3 мес - запрос идёт из каталога (source_type = NETWORK) Множитель: +0.3 к нормализованному score (0..1) Эффект: SKU гр. 2 поднимаются в выдаче, но не блокируют других Защита (ст. 10.3): - Приоритет ТОЛЬКО из сетевого притока - Мигрировавшая база другого селлера НЕ перераспределяется - Покупатель, пришедший в магазин селлера A напрямую, никогда не маршрутизируется к селлеру B

Как определяется source_type

Логика определения source_type при создании заказа: if order.entry_point == "SHOP": // Покупатель пришёл в магазин селлера напрямую order.source_type = "MIGRATED" elif order.entry_point == "CATALOG": // Покупатель пришёл из каталога Системы order.source_type = "NETWORK" elif order.entry_point == "CHANNEL": // Покупатель пришёл через канал селлера (TG, VK, IG) order.source_type = "MIGRATED" elif order.entry_point == "REFERRAL" and referrer == seller: // Прямая ссылка от селлера order.source_type = "MIGRATED" Важно: - source_type фиксируется на ПЕРВОМ заказе покупателя - При повторном заказе у ТОГО ЖЕ селлера — тип сохраняется - При заказе у ДРУГОГО селлера через каталог — NETWORK - Мигрировавший покупатель НЕ «переходит» к другому селлеру даже если купил у него через каталог
Зачем разграничение (норма К4). Разграничение защищает доверие участника, приводящего своих клиентов: он не теряет их в пользу других. Иначе исчезает стимул наполнять общую базу.

Мульти-селлер корзина (каталог)

В каталоге покупатель может добавить товары от разных селлеров. Каждый селлер — отдельный заказ (Deal) в Deal Engine. Одна оплата → N сделок.

Преимущества перед Ozon/WB кабинетом

Что получает селлер и чего нет на маркетплейсах: ✓ 100% выручки (vs 15–55% комиссия Ozon/WB) ✓ Собственный бренд (магазин, логотип, каналы) ✓ Своя клиентская база (мигрировавшая не перераспределяется) ✓ 5 каналов продаж (vs зависимость от одной площадки) ✓ Фиксированные правила (vs штрафы и изменения задним числом) ✓ Выплата 1–3 дня (vs недели ожидания) ✓ Нет штрафов за упаковку / габариты / склад ✓ Свобода выбора фулфилмента (Волна 2)
