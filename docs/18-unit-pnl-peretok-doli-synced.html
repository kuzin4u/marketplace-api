Юнит-экономика одного селлера при перетоке

Доход одного селлера в режиме разделения: часть оборота идёт через маркетплейс (удержание ~40%), часть через Систему (12,5%), и доля Системы растёт во времени. Модель показывает, как совокупная прибыль селлера меняется по мере перетока — для каждой группы и размера.
