Подключение селлера · Полная процедура

Технология · Организация · Финансы · Юридика · От заявки до первой продажи за 48 часов
Синхронизировано с Правилами системы · редакция 2
Полный цикл: от регистрации до покупки. Селлер проходит join-form (ИНН, OTP, группа) → wizard (бренд, каналы, акцент) → sku-crud (товары, цены, фото) → ЛК селлера (управление). Данные записываются в Supabase через API (server.js на Render). Витрина рендерится из API, агент покупателя (виджет 🤖) работает поверх того же API. Покупатель покупает через витрину (MIGRATED) или через агента (NETWORK). Два каталога: 🟢 Система + ⚪ рынок.
Связанные документы: Витрина двухуровневая · Прототип витрины · Полный цикл: от селлера до покупателя · Полный цикл (ред. 2 — два сервиса) · Архитектура агентного слоя · Быстрый онбординг
Настоящий документ действует в рамках Правил системы (ред. 2) и подчинён им при любом расхождении. Процедуры ниже реализуют следующие статьи Правил:

Целевые показатели подключения

Подключение селлера — конкурентное преимущество Системы. У Ozon регистрация занимает 3–7 дней, у WB — 1–3 дня. Цель: 48 часов от заявки до первой продажи, включая юридическое оформление.

Ключевое отличие. На Ozon/WB селлер получает «витрину в чужом магазине» — его SKU тонет среди миллионов. В Системе селлер получает собственный магазин с брендом + место в каталоге Системы. Два уровня витрины = два потока покупателей с первого дня.

Финансовые условия подключения

Два слоя условий. Единовременные (при вступлении): регистрация, ПО магазина, создание витрины — всё 0 ₽, депозита нет. Это барьер входа, он минимален осознанно. Текущие (во времени): расчётный тариф 0,2→0,5% + опциональный взнос на инфраструктуру только за сверх-базовый уровень (co-payment по потреблению, не с оборота). Базовый доступ бесплатен всегда (Правила ст. 7.3). Комиссия-налог с оборота не взимается ни с кого — доход Организатора идёт из расчётов и финпотоков (ст. 7.1).

AI-помощник для селлера

AI-ПОМОЩНИК (Claude Haiku, как в Масса Матере) Возможности: ├── Анализ фото товара → предложение описания и категории ├── Оптимизация карточки: «Добавьте ключевые слова: ...» ├── Ответ на вопросы покупателей (автоматический) ├── Генерация текста для Instagram / VK постов ├── Анализ конкурентов: «Средняя цена в категории: ...» └── Подсказки по ранжированию: «Ваш товар на #7, добавьте ещё 2 фото» Доступ: в ЛК (чат-виджет) + Telegram-бот (inline) Стоимость для селлера: бесплатно (входит в подключение)
