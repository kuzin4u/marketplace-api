Трек A: Платформа (без эскроу)Трек B: Эскроу + клиринг
ЧтоВитрина + каталог + подключение селлеровНСВР, банк API, Clearing Engine
ЗависимостьТолько от разработкиБанк (внешний контракт)

КлирингРучной (Организатор считает доли)Автоматический (Clearing Engine)

Решение. Запускаем Трек A сейчас. Трек B — параллельно, подключается когда банк готов. Селлеры Волны 1 начинают БЕЗ эскроу (оплата напрямую), переходят на эскроу когда банк API готов. Витрина и каталог — ценность сами по себе, без привязки к эскроу.
